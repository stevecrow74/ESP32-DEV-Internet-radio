ESP32 Smart Radio V2 - User Manual

Web version of the manual. Use this page for quick setup and daily operation.

1. Quick Start

  1. Power on the radio.
  2. Wait for startup and Wi-Fi connection.
  3. Use the right encoder to change station and widgets.
  4. Open http://DEVICE_IP/ for Web UI management.

2. Encoder Controls

Left Encoder (Volume)

  • Rotate: Volume up/down
  • Press: Mute/unmute

Right Encoder (Station/Widgets)

  • Rotate: Next/previous favourite station (normal mode)
  • Press: Next widget

Main station browsing uses your favourites list.

Startup default is Rewind when present in favourites.

In Favourites Widget

  • Rotate: Move selection
  • Short press: Play selected favourite
  • Long press (~5s): Delete selected favourite

3. Widgets

  • Clock
  • ADS-B
  • Weather
  • Tides
  • Audio
  • Favourites

Widgets auto-cycle every ~10 seconds.

Favourites is excluded from auto-cycle and available by manual widget switching.

4. Web UI Pages

  • / Home
  • /favourites Manage favourite stations
  • /adsb ADS-B feed and range settings
  • /tides Tides location and refresh settings
  • /network Wi-Fi join, saved credentials, AP mode

5. Defaults

  • Weather area: Clarinbridge
  • ADS-B reference area: Clarinbridge
  • Tides label: Galway
  • Timezone: Irish time (DST aware)

ADS-B and tides settings can be changed in Web UI and are saved to SPIFFS.

6. Network and AP Mode

  • Use /network to scan and connect to Wi-Fi.
  • Save SSID/password entries for quick reconnect.
  • AP mode SSID: ESP32-Radio-AP
  • AP mode IP: 192.168.2.1

7. Troubleshooting

  • No audio: check mute, volume, and stream URL.
  • No Web UI: confirm device IP and same network.
  • No Wi-Fi: use AP mode and open 192.168.2.1.
  • Bad ADS-B/Tides data: verify settings and save again.
